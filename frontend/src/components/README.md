# Frontend Components
This directory contains reusable UI components such as:
- `Navbar.jsx`: Role-aware top navigation bar
- `Sidebar.jsx`: Dashboard sidebar navigation
- `BookCard.jsx`: Book presentation card with action triggers
- `BookModal.jsx`: Modal for Adding/Editing books (ADMIN only)
- `BorrowModal.jsx`: Confirmation modal for borrowing books (STUDENT)
- `ProtectedRoute.jsx`: Role-based route protection wrapper
- `StatCard.jsx`: Metric counters for dashboards
