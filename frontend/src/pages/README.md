# Frontend Pages
This directory contains the main page views:
- `Login.jsx`: User login view with role redirection
- `Register.jsx`: Student registration page
- `AdminDashboard.jsx`: Administrative dashboard (manage books, inventory, all borrowings)
- `StudentDashboard.jsx`: Student portal (browse catalog, active loans, fines)
- `BooksCatalog.jsx`: Book catalog view with search and filter
- `BorrowedBooks.jsx`: Student borrowed books & history
- `NotFound.jsx`: 404 error page
